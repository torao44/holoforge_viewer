# HoloForge Viewer

> 単一HTMLファイルの3D CADビューワー。Three.js r160 を搭載し、ブラウザだけで動作します。

## 概要

HoloForge Viewer は、3D CAD ファイルをブラウザ上で手軽に表示・確認できる軽量ビューワーです。サーバーやインストール作業は不要で、単一の HTML ファイルを開くだけですぐに使えます。

Android Chrome での実機動作を最適化し、タッチ操作・全画面表示・ファイル選択・ドラッグ&ドロップに対応しています。

## 対応フォーマット

| フォーマット | 拡張子 | 備考 |
|---|---|---|
| glTF / GLB | `.glb`, `.gltf` | テクスチャ・マテリアル対応 |
| STL | `.stl` | 3Dプリント標準フォーマット |
| OBJ | `.obj` | 頂点色対応 |
| 3MF | `.3mf` | 3D Manufacturing Format（Production Extension 含むフォールバック対応） |
| PLY | `.ply` | 頂点色情報対応 |
| FBX | `.fbx` | Autodesk フォーマット |
| COLLADA | `.dae` | XMLベース3Dフォーマット |
| STEP | `.step`, `.stp` | CAD標準（occt-import-js WASM変換） |
| IGES | `.iges`, `.igs` | CAD標準（occt-import-js WASM変換） |
| ZIP | `.zip` | 上記フォーマットの自動展開・読み込み |

## 主な機能

### 表示機能
- **3つの表示モード切り替え**: テクスチャ（オリジナル）/ 単色 / ホログラム
- **ホログラムモード**: スキャンライン・フレネル輝光・ノイズエフェクトを搭載したSF風表示
- **背景色変更**: ダーク / ネイビー / チャコール / ライト / カスタムカラー
- **グリッド表示 ON/OFF**

### モデル操作
- **1本指ドラッグ**: 回転
- **2本指ピンチ**: ズーム
- **2本指ドラッグ**: パン
- **ダブルタップ**: 表示範囲の再調整（スライドショー時は次のモデルへ）

### 向き補正
- **自動正立**: バウンディングボックスから最も大きい面を底面に自動回転
- **Y-up / Z-up 切り替え**: CG座標系とCAD座標系をワンタップで切り替え
- **向きリセット**: 回転を初期状態に戻す

### 分解表示
- 6種類の分解パターン: 放射状 / 上下 / 左右 / 前後 / 円形 / グリッド
- 自動パーツ分割機能（単一メッシュから連結領域を検出して分割）

### 自動回転
- 低速 / 普通 / 高速 の3段階速度設定
- 回転中はボタンがシアンに発光し、アイコンも回転アニメーション

### 録画機能
- 1回転分のループ動画を WebM/MP4 で保存
- 自動回転と連動して滑らかな1周分をキャプチャ

### スライドショー
- フォルダ選択（`webkitdirectory`）で一括登録
- 30秒 / 1分 / 3分 / 5分 の切替間隔
- IndexedDB にフォルダ情報を保存し、次回起動時に自動復元
- ZIP ドロップ時もスライドショーに登録可能

### UI
- 下部ツールバーにアイコン配置（SVG細線アイコン）
- UI アイドル 4.5秒で自動非表示（タップで復帰）
- 全画面表示対応（Android Chrome 最適化）
- ローディング画面・進捗バー・トースト通知

## 使い方

### 1. ファイルを開く
1. 画面右上の「ファイル」ボタンをタップ
2. 3Dファイル（`.stl`, `.obj`, `.glb`, `.3mf` など）を選択

### 2. ドラッグ&ドロップ
1. PC または Android のファイルマネージャーからファイルを選択
2. ブラウザ画面にドラッグ&ドロップ（複数ファイル・ZIP可）

### 3. スライドショー
1. 下部ツールバーのスライドショーボタンをタップ
2. 「フォルダを選択」で3Dファイルが入ったフォルダを選択
3. 「開始」で自動切替を開始

## インストール

このアプリは単一の HTML ファイルのみで構成されています。特別なインストールは不要です。

```bash
# 任意の方法でローカルサーバーを立ち上げてアクセス
# 例: Python
python -m http.server 8000

# 例: Node.js
npx serve .
```

Android Chrome で使用する場合、同一ネットワーク内の PC でサーバーを立ち上げて `http://<PCのIP>:8000/holoforge_viewer_v1.4.0.html` にアクセスしてください。

## 技術仕様

- **Three.js**: r160
- **レンダラー**: WebGLRenderer（ACESFilmicToneMapping, SRGBColorSpace）
- **環境光**: RoomEnvironment IBL + HemisphereLight + DirectionalLight x3
- **ローダー**: GLTFLoader, STLLoader, OBJLoader, ThreeMFLoader, PLYLoader, FBXLoader, ColladaLoader
- **圧縮/変換**: JSZip（ZIP展開）, occt-import-js（STEP/IGES変換）, fflate（3MF内蔵）
- **PWA**: 対応（manifest.json + Service Worker によるオフライン化も可能）

## 注意事項

- STEP / IGES ファイルの読み込みには `occt-import-js` の CDN 読み込みが必要です。初回変換時に数秒かかる場合があります。
- オフライン環境では STEP / IGES の読み込みができません。
- 大容量モル（数百万ポリゴン以上）はデバイスの性能によって動作が遅くなる場合があります。
